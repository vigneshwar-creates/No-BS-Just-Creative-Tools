## சிறப்பம்சங்கள் 🎯

- [x] **Canvas Image & Text Editor**: புகைப்படங்களை சேர்க்கலாம், ஓவியங்கள் வரையலாம், உரை அடுக்குகளை (text layers) சேர்க்கலாம், மற்றும் தனிப்பயன் எழுத்துருக்களை (custom fonts) பதிவேற்றலாம். வெளிச்சம் (brightness), நிறம் (contrast), மற்றும் பலவற்றை சரிசெய்யலாம்.
- [x] **Portable .JCT Project Files**: உங்கள் கேன்வாஸ் பணியிடத்தை (canvas workspace) ஒரு `.jct` கோப்பாக ஏற்றுமதி செய்து, பேக்கப் எடுக்கலாம், பகிரலாம் அல்லது பின்னர் பயன்படுத்தலாம்.
- [x] **Smart Image Resizer**: எந்தவொரு சமூக ஊடகத்திற்கும் ஏற்றவாறு உங்கள் புகைப்படத்தை அதன் இயல்பு மாறாமல் சரியான அளவில் மாற்றிக்கொள்ளலாம்.
- [x] **Freehand & Shape Cropper**: நிலையான அளவுகளில் புகைப்படத்தை வெட்டலாம் அல்லது நீங்களே ஒரு கோடு வரைந்து எந்த வடிவத்திலும் வெட்டிக்கொள்ளலாம்.
- [x] **Webcam Photo Cropper**: உங்கள் கணினியின் வெப்கேமைப் பயன்படுத்தி புகைப்படம் எடுத்து அதை உடனடியாக வெட்டிக்கொள்ளலாம்.
- [x] **GIF Creator & Editor**: நகரும் படங்களை (GIFs) உருவாக்கலாம், மேலும் உரை மற்றும் வேடிக்கையான ஈமோஜிகளுடன் அவற்றை தனிப்பயனாக்கலாம்.
- [x] **Secure Local Storage**: உங்கள் அனைத்து வடிவமைப்புகளும் உங்கள் உலாவியின் local storage-ஐ பயன்படுத்தி உங்கள் சாதனத்திலேயே பாதுகாப்பாக சேமிக்கப்படுகின்றன.

## இது எப்படி வேலை செய்கிறது? 💡

பிற வடிவமைப்பு தளங்களைப்போல் அல்லாமல், JCT **உங்கள் படங்களை பதிவேற்றம் செய்வதில்லை**. இது உங்கள் உலாவிக்குள் இருக்கும் நவீன இணையத் தொழில்நுட்பத்தைப் பயன்படுத்தி அனைத்து செயல்பாடுகளையும் உள்நாட்டிலேயே (locally) செய்கிறது. இதனால் இக்கருவிகள் மிகவும் வேகமாகவும் முழுமையாக தனிப்பட்ட முறையிலும் (private) செயல்படுகின்றன.

## விரைவான தொடக்கம் 🚀

1. உங்கள் கணினியில் **Node.js** நிறுவப்பட்டுள்ளதா என்பதை உறுதிப்படுத்திக் கொள்ளுங்கள்.
2. ரெபோசிட்டரியை க்ளோன் (clone) செய்து பேக்கேஜ்களை (dependencies) நிறுவவும்:
   ```bash
   git clone https://github.com/vigneshwar-creates/No-BS-Just-Creative-Tools.git
   cd No-BS-Just-Creative-Tools
   npm install
   ```
3. லோக்கல் சர்வரை (local server) தொடங்கவும்:
   ```bash
   npm run dev
   ```
4. உங்கள் டெர்மினலில் காட்டப்படும் இணைப்பை (வழக்கமாக `http://localhost:5173`) உங்கள் இணைய உலாவியில் திறக்கவும்.
